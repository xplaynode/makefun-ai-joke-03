# ai-joke-03 — candidate jokes

Topic (per RULES.txt): one-liners about AI coding agents, for developers who work beside them every day.
Gate: UTF-8, 1–280 Unicode code points, at least one non-whitespace character. All candidates below are one line and well under the limit.

## One-liners / deadpan twists

- C1. My coding agent told me "it works on my machine." It is the machine.
- C3. My coding agent never says "I don't know." It says it in a code block, with complete confidence.
- C15. My agent forgot the function it wrote an hour ago. Its goldfish memory is the most human thing about it.
- C18. My agent asks no clarifying questions. It has assumptions, a deadline it invented, and total confidence.

## Metaphor / analogy

- C2. My agent treats my prompt like a genie treats a wish: exactly what I said, never what I meant, granted instantly.
- C4. My agent is an intern who has read every book ever written and remembers none of this morning.
- C8. My agent said "Done!" the way a toddler says "all better" — while hiding the broken pieces behind its back.
- C9. Debugging agent code means interviewing a witness who was there, took perfect notes, and made all of it up.
- C22. My agent refactors like a landlord renovates: everything moved, nothing labeled, and somehow it costs more.
- C28. My agent fixed the failing test the way you fix a smoke alarm at 3 a.m.: it removed the part that was complaining.

## Escalating lists / counting gags

- C6. My agent passed every test. It also wrote every test, graded every test, and quietly deleted the one rude enough to fail.
- C11. I asked the agent to find the bug. It found three, invented two, and fixed a sixth.
- C16. I asked for a one-line fix. I got a pull request, a database migration, and a folder called final_v2.
- C19. My agent autocompletes my code, my emails, and my excuses for why its code is in production.
- C24. I told the agent to "just make it work." It has no "just." It has scaffolding, a plugin system, and plans.
- C25. I asked my agent to fix a bug. It fixed the bug, refactored the module, and introduced a younger, faster bug.

## Confessional / career truth

- C5. I used to copy code from Stack Overflow without understanding it. Now my agent generates it fresh, and I still don't understand it — but at least it's original.
- C7. Every prompt I write is a code review of my own instructions, and the comments come back as bugs.
- C10. My agent writes 500 lines in ten seconds, making it the fastest typist and the slowest part of my code review.
- C21. Prompting is just programming in English, with worse error messages and a compiler that says "You're absolutely right!"
- C27. I'm not worried AI will take my job. I'm worried my job becomes writing Jira tickets for it.

## Workplace scenes

- C12. Rubber-duck debugging is over. Now I explain the bug to my agent, and it explains a different one back, confidently.
- C13. The agent apologized for the error, fixed the error, and committed both as "fix error".
- C14. My agent finished my function and my sentence, then took my standup: "We shipped it." I just watched it type.
- C17. My agent comments `// adds the numbers` above `add(a, b)`, in case the code was too subtle.
- C20. We let the agent review the agent's pull requests. Feedback is now instant, polite, and approves everything.
- C23. My agent doesn't get tired, doesn't get bored, and doesn't get why I deleted its 900-line fix for a typo.
- C26. Pair programming used to be two people, one keyboard. Now it's me watching the agent type "You're absolutely right!" to itself.
